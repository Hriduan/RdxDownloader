# Changelog

## v1.0.2
- Connected GitHub Pages to the deployed Render HTTPS backend.
- Added free-host cold-start messaging and bounded request timeouts.
- bash update no longer requires typing RELEASE; --review remains available.
- Added one-time GitHub CLI device authorization instructions and free-tier configuration.
- Added a generated audiovisual fixture for deployed end-to-end verification.


## v1.0.1 — Compatibility and Termux repair

- Included the safe ZIP-import/snapshot publisher and regression tests for unrelated Git histories.
- Added highest-remote-tag version advancement and explicit --snapshot publishing.
- Added native Termux setup, HOME-based environment, portable temp storage, start helper and offline doctor.
- Enabled sandboxed Deno with the locally installed matching EJS solver; Docker includes the runtime.
- Added five named source families, conservative link normalization, generic/direct public media and safe source-specific errors.
- Added compatible MP4 merging, actual resolution filtering, browser backend settings and dependency diagnostics.
- Preserved twelve external manual ad slots, access-control restrictions, network guard and resource ceilings.

## v1.0.0 — Initial release

- Root-level responsive interface with light/dark themes, clipboard input, video/audio formats and job progress.
- Public-video extraction backend powered by yt-dlp, native stream fetching and local FFmpeg merging.
- Explicit rights confirmation, source-available qualities and honest watermark/audio limitations.
- Twelve manual ad placements outside the downloader; disabled-by-default Google/Adsterra configuration and consent-aware loading.
- Temporary download capabilities, bounded queues, worker timeouts, file/duration limits and public-network checks.
- Docker deployment, optional separate-backend Pages workflow, safe version/update helper and illustrated README.
