# Security and abuse

Do not submit sensitive URLs, credentials, cookies, private media or source account information. Download only authorized public media. Internal-network URLs, DRM, private/login-only sources and remote FFmpeg downloading are not supported.

Operators: review docs/DEPLOYMENT.md and docs/ARCHITECTURE.md before launch. Add a restrictive outbound firewall, public/private network isolation, HTTPS and edge abuse limits; run the non-root container; keep Python, FFmpeg and yt-dlp updated. Do not advertise the starter as security-audited or infinitely scalable. Add a monitored abuse/copyright/privacy contact and any legally required notices.

If GitHub private vulnerability reporting is enabled on the repository, use its Security tab for sensitive findings. Otherwise contact the repository owner privately using an available verified channel. Do not publish secrets, exploit payloads or private user links in a public issue. No specific monitored contact is claimed by this source package.
