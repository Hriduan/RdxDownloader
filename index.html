    05 / THE SMALL PRINT, IN PLAIN WORDS.

    Good questions.
    Clear answers.

    A useful tool should be honest
    about what it can—and can’t—do.

    Can I download from absolutely any website?

    No. The backend supports many yt-dlp extractors, but private, login-required, DRM-protected, age-restricted or unsupported media may not work. Platforms also change their systems.

    Is it free? Is there a watermark?

    This project has no subscription or per-download charge. The host may set resource limits. No watermark is added. Watermarks already part of the source video may remain.

    Where are the higher resolutions and the sound?

    Only formats exposed by the source are listed. Higher-quality video often has separate audio. The backend uses FFmpeg to merge streams without re-encoding. Compatible H.264/AAC streams can use MP4; other combinations may use MKV.

    Can I use it for copyrighted or protected videos?

    Only download content you own, have permission to download, or that applicable licensing and law allow you to save. This project does not bypass DRM, logins, paywalls or access controls.

    How long are prepared files kept?

    Prepared jobs are temporary, normally expiring after one hour. Expired files are removed by the server’s cleanup task. Files are not a permanent library, and anyone holding a download link can access it until expiry.

    Why does it say “Backend setup required”?

    The frontend can live on GitHub Pages, but downloads need the included Python backend and FFmpeg. The repository contains a Docker setup and deployment instructions. GitHub Pages cannot run this backend.

    A FRONTEND NEEDS AN ENGINE.

    Connect your backend.

    Use the public HTTPS origin of the backend you deployed. GitHub Pages alone cannot run Python or FFmpeg. For this same-origin server, leave the field empty.

    Local testing also accepts http://127.0.0.1:8080 or localhost. No credentials, paths, or tokens belong here. The backend must allow this frontend’s origin.
